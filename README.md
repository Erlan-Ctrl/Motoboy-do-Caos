# Motoboy-do-Caos
Corre, Zé! é um game interativo inspirado no trânsito brasileiro, onde um motoboy precisa concluir sua entrega enquanto espectadores do TikTok provocam obstáculos ou ajudam pelo caminho. Ambientado nas favelas do Rio de Janeiro, combina cenários 3D, Brazilian Phonk e gameplay caótica e divertida.
